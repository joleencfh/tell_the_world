Decision 3 · Brief page

The reading font for brief sections

The same section, set three ways. Brief sections are in sans today. The Q&A and quotes already use serif in the new design. Read each one as if you were reading a brief for real.

A. Serif, 19px

Recommended
02What we know

Auditors can test a model without seeing inside it

In short: outside testers can learn a lot from careful questions alone, but some risks only show up with deeper access.

Most outside evaluations today work through the same chat window the public uses. Testers write many prompts, record the answers and look for patterns. This approach is cheap, and it needs no cooperation from the company that built the system.

Its limit is that a model can behave well in a test and differently in the field. Researchers call this a gap between what was measured and what was meant, and closing it usually requires access to training data, internal notes or the model's own working.

Warm and book-like, matches the Q&A and quotes, best for sustained reading. EB Garamond runs small for its size, so 19px is the floor.
