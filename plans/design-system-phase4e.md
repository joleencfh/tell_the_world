Lessons carried from 4a to 4d (CI failed on these every time; apply in every step):
- Unexecuted specs fail in CI on old-UI assumptions: read the markup of every asserted element; avoid strict-mode multi-matches (scope locators, exact names); hover-only text is `display:none` (`toBeAttached`, not `toBeVisible`); focus return can only be asserted when the opener stays mounted; prefer `data-testid` over class selectors.
- A class string with a missing space silently drops a utility (`z-[var(--z-dropdown)]min-w-...` in 4a): after editing, grep changed files for fused utilities with `grep -nE "\][a-z]"` inside class strings. A dropdown or popover inside an `anim-rise` wrapper is trapped in a local stacking context under the sticky section nav (`z-10`): lift it (see `app/briefs/[slug]/brief-hero.tsx`).
- The final step sweeps `tests/` for assertions on old classes or colours.
